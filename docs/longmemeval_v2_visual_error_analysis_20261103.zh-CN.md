# LongMemEval-V2 首轮 12 道错题分析

这 12 题来自首轮 20 题中旧 Harness 的错误结果，只用于开发诊断；后续问题留出集排除首轮全部 20 个题目 ID 和规范化正文哈希。两个历史库仍复用，不能称为来源或任务模板完全独立的留出实验。

可直接确认的工程问题：4 题最终生成以 `finish_reason=length` 结束，没有交付规范的最终短答案；10/12 错题的中间 review 曾宣布证据完整，说明“引用范围存在”不足以证明答案正确。跨页题还出现最终截图换成另一页、初始页面原图未再次附带的现象。以下其余原因是从保存的轨迹、原图和评审记录提出的诊断，未经逐条人工建立穷尽的 oracle 证据集。

新版门控区分三种情况：观察支持答案、观察明确反驳问题前提、仍缺少证据。前提被反驳时应给出明确纠正；缺少证据才返回 UNKNOWN。引用 ID、原字段范围、原图哈希和物理请求绑定由程序核验，语义支持关系仍是模型判断，不能宣称形式化证明。

开发阶段的失败试验也保留：初版严格门控过度拒答，没有把相互依赖的前提条件与下游问题分开，且没有跨轮固定部分支持证据。后续修正加入历史轨迹目录路由、部分支持累积和依赖取消。正式留出评测将在这些修改完成且代码固定之后开始；不得用留出结果继续调优后仍称其为新样本。
