# CRU-Harness v3.2.0

**Context Is All You Need — Context Read and Understand Harness**

[English README](../../README.md) · [简体中文 README](../../README.zh-CN.md)

CRU-Harness is released as a standalone software work for extending the source
context accessible to bounded-window language models. The repository includes
complete English and Chinese READMEs, portable source packages, an offline
mechanism demonstration, tests, a project proposal and a machine-readable
benchmark summary.

## Technical scope

- Separate complete source storage from the model's working context.
- Accumulate source-bound facts and settle record queries with typed local
  aggregation, including conditional grouping.
- Reuse classification across strictly identical bodies while preserving
  physical record identities and multiplicities.
- Track unknown bounds, convergence and a shared generation budget.
- Retain independent provenance, fact-preservation and scoring audits.

## Latest benchmark evidence

The external benchmark is **OOLONG-synth**. Its official sources, exact data and
scorer revisions, sample-selection protocol and baseline adaptations are
documented in [the benchmark report](../benchmark_v32.md) and
[related-work comparison](../related_work.md).

- 12 held-out source contexts, all exceeding the tested Qwen service's reported
  262,144-token native limit.
- 9/12 full-credit tasks, a 75.00% full-credit rate and an 81.25/100 official mean
  score under shared budget ceilings.
- Maximum measured source: 1,866,427 Qwen tokens, or 7.12 times that native limit.
- Longest full-credit source: 1,792,309 tokens, or 6.84 times that native limit.
- 27.74% lower average model token usage than the locally adapted RLM baseline
  in this pilot, with official means of 81.25 versus 58.33.

These are local, frozen pilot results, not an official leaderboard submission
or proof of general statistical superiority. Source-context expansion does not
change the base model's single-call attention window. The original evaluation
method identifiers, revisions, numerical results and code fingerprints remain
unchanged by this independent branding release.

## Verification and use

The portable snapshot passed 335 tests, and its standard-library demonstration
ran without network access or model credentials. Real model execution requires
an OpenAI-style chat endpoint, precise tokenization and usage accounting. Full
three-method reruns additionally require the fixed external baseline code,
dependencies and official source data; these are not bundled as an opaque
runtime image.

The project does not bundle private source corpora, provider traces or
credentials. Third-party scoring code retains its original MIT notice. A
project-wide open-source license has not been assigned.
