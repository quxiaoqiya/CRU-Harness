31.34%。501 页不是另一次预注册、独立生成的实验。

## 来源、隔离和预算

- 视觉 QA：[MMLongBench-Doc](https://huggingface.co/datasets/yubo2333/MMLongBench-Doc)，固定 revision `2ff6aa9237fc777b6627dc57a486e9225ac5fb86`。7 个目标 PDF 不在此前使用的 47 份来源语料中，四道颜色题、三道计数题。验证 Git/LFS 字节；一份字节不符的 PDF 在推理前排除。选题不读取答案列。
- 全局计数：[DocLayNet 1.0](https://github.com/DS4SD/DocLayNet) 的人工 Picture/Table 布局标注派生任务；[官方 ZIP](https://codait-cos-dax.s3.us.cloud-object-storage.appdomain.cloud/dax-doclaynet/1.0.0/DocLayNet_core.zip)，ETag `52242220284e12538949c5b06eb2777c-448`。字节范围下载，核对 ZIP CRC32 和 PNG SHA256。不是原版布局检测 benchmark 得分。
- 初始选择 2,100 张 test 正例及 6 张独立验证页。每张全局 test 页都至少有一个人工 Picture 或 Table；按固定哈希顺序选择，不按计数大小排名。框、数量不传给模型。新 502 页从剩余 821 个合格文件名按另一固定哈希顺序选择。
- 原生 C = 262,144；复用上一轮实际边界校准，结合本轮服务元数据、分词器核对。官方 1025×1025 PNG 每张为 1,026 个图像及标记 tokens，消息和文本另计。1/2/6 图实测与分量核算一致。
- 各方法同上限：单次 C、累计 12C = 3,145,728、最多 160 次生成、最多 16,384 输出、temperature=0、seed=20261105。实际用量不同。旧版保留 24 次工具执行的内部限制；v2.1 每批 16 页、使用 2,048 输出额度。控制器差异使结果不能全部归因于记忆算法。
- 46 条原始预测、5 条确认预测和零调用格式恢复结果均在参考答案首次打开前固定哈希。v2.1 根据旧响应的结构问题开发，不看新页参考计数。可信 Python 标签读取防护不等于操作系统级隔离。

全局题要求每页参与，按文件名过滤后不能减少来源。502 页相关原图本身 515,052 tokens > C，
502 张又低于服务 999 张图片上限，不能把该档容量问题归因于图数限制。501 页切片
相关原图 514,026 tokens，约 1.961C。**尚未证明最小充分证据或最优裁剪也超过 C。**

## 像素重复更正：501 页事后切片

`5405019d57fd1e2ee05d12cd026cde62fccf71b55e4ca8c710f5474a3d62ba90`
